# 🔌 Аксессуары и периферия

## 📋 Обзор

Система позволяет привязывать аксессуары и периферию к оборудованию (ПК, ноутбуки) через удобные чекбоксы. Это помогает отслеживать полную комплектацию рабочего места.

## 🎯 Возможности

### 1. Привязка аксессуаров к оборудованию

**Доступные типы аксессуаров:**
- 🖱️ Мышь
- ⌨️ Клавиатура
- 📷 Веб-камера
- 🎧 Гарнитура
- 🔊 Колонки
- 🔌 USB-хаб
- И другие (можно добавлять свои)

### 2. Управление типами аксессуаров

Администраторы могут:
- Добавлять новые типы аксессуаров
- Редактировать существующие типы
- Удалять типы (деактивировать)
- Выбирать иконки для типов

### 3. Улучшенный поиск оборудования в связях

При создании связей между оборудованием:
- Поиск по названию оборудования
- Поиск по сотруднику (ФИО)
- Поиск по инвентарному номеру
- Отображение информации о сотруднике в результатах поиска

## 🔧 Как использовать

### Привязка аксессуаров к оборудованию

1. **Откройте карточку оборудования**
   - Перейдите в "Оборудование" → выберите ПК или ноутбук

2. **Найдите секцию "🔌 Аксессуары и периферия"**
   - Прокрутите вниз до секции с аксессуарами

3. **Нажмите "Добавить аксессуар"**

4. **Выберите тип аксессуара**
   - Выберите из списка доступных типов (мышь, клавиатура и т.д.)

5. **Укажите количество** (если нужно)
   - По умолчанию: 1
   - Можно указать больше (например, 2 мыши)

6. **Добавьте заметки** (опционально)
   - Например: "Logitech M185", "Беспроводная"

7. **Нажмите "Добавить"**

### Удаление аксессуара

1. **Найдите аксессуар в списке**
   - В секции "🔌 Аксессуары и периферия"

2. **Нажмите кнопку 🗑️**
   - Рядом с нужным аксессуаром

3. **Подтвердите удаление**

### Управление типами аксессуаров

1. **Откройте страницу "Типы аксессуаров"**
   - Перейдите в "Система" → "Типы аксессуаров"

2. **Добавить новый тип**
   - Нажмите "+ Добавить тип"
   - Введите название
   - Выберите иконку из списка
   - Нажмите "Создать"

3. **Редактировать тип**
   - Нажмите ✏️ рядом с типом
   - Измените название или иконку
   - Нажмите "Сохранить"

4. **Удалить тип**
   - Нажмите 🗑️ рядом с типом
   - Подтвердите удаление

### Создание связей с поиском

1. **Откройте карточку оборудования**
   - Перейдите в "Оборудование" → выберите оборудование

2. **Найдите секцию "🔗 Связи оборудования"**
   - Нажмите "Добавить связь"

3. **Выберите тип связи**
   - Добавить дочернее или родительское

4. **Выберите тип отношения**
   - Компонент, Монитор, ИБП и т.д.

5. **Используйте поиск**
   - Введите название оборудования или ФИО сотрудника
   - Результаты фильтруются в реальном времени
   - Отображается информация о сотруднике

6. **Выберите оборудование из списка**
   - Кликните по нужному оборудованию
   - Оно подсветится зелёным

7. **Нажмите "Добавить"**

## 📊 Отображение аксессуаров

В карточке оборудования отображаются:

### Список аксессуаров
- Иконка типа аксессуара
- Название типа
- Количество (если > 1)
- Заметки (если есть)
- Кнопка удаления

### Статистика
- Общее количество аксессуаров
- Типы аксессуаров с количеством

## 🔍 Поиск оборудования в связях

### Возможности поиска

**По названию оборудования:**
- Частичное совпадение
- Регистронезависимый поиск
- Мгновенные результаты

**По сотруднику:**
- Поиск по ФИО
- Отображение ФИО в результатах
- Иконка 👤 для оборудования с сотрудником

**По инвентарному номеру:**
- Точное или частичное совпадение
- Отображение инвентарного номера

### Формат результатов поиска

```
Название оборудования
Тип • Инвентарный номер • 👤 ФИО сотрудника
```

Пример:
```
Ноутбук ThinkPad X1
Ноутбук • INV-001 • 👤 Иванов Иван Иванович
```

## 🔍 Решение проблем

### Проблема: Аксессуары не отображаются
**Решение:**
1. Обновите страницу (F5)
2. Проверьте, что оборудование сохранено
3. Проверьте консоль браузера на наличие ошибок

### Проблема: Не могу добавить аксессуар
**Решение:**
1. Убедитесь, что выбран тип аксессуара
2. Проверьте, что оборудование сохранено
3. Проверьте права доступа

### Проблема: Поиск не находит оборудование
**Решение:**
1. Проверьте правильность написания
2. Попробуйте искать по инвентарному номеру
3. Проверьте, что оборудование не привязано к текущему

### Проблема: Не отображается ФИО сотрудника
**Решение:**
1. Убедитесь, что у оборудования указан сотрудник
2. Проверьте, что сотрудник существует в системе
3. Обновите страницу

## 💡 Советы по использованию

### Организация аксессуаров

- Используйте заметки для указания модели аксессуара
- Указывайте количество для одинаковых аксессуаров
- Группируйте аксессуары логически

### Поиск оборудования

- Используйте короткие запросы для быстрого поиска
- Ищите по фамилии сотрудника для быстрого нахождения
- Используйте инвентарный номер для точного поиска

### Управление типами

- Создавайте типы заранее перед привязкой аксессуаров
- Используйте понятные названия
- Выбирайте подходящие иконки для визуального удобства

2. Нажмите "Добавить связь"

# 📥 Руководство по импорту данных из Excel

## 📋 Обзор

Система ITAM Service поддерживает массовый импорт данных из Excel файлов (форматы XLS и XLSX). Доступны два типа импорта:

1. **Импорт сотрудников** - создание сотрудников с подразделениями и должностями
2. **Импорт оборудования** - создание оборудования с характеристиками и привязками

## 🔐 Доступ

Функционал импорта доступен только пользователям с ролью **Администратор**.

## 📥 Импорт сотрудников

### Формат файла

Скачайте шаблон через интерфейс: **Система → Импорт данных → Скачать шаблон для сотрудников**

#### Структура файла:

| Колонка | Обязательность | Описание | Пример |
|---------|----------------|----------|--------|
| Фамилия | ✅ Обязательно | Фамилия сотрудника | Иванов |
| Имя | ✅ Обязательно | Имя сотрудника | Иван |
| Отчество | ⚪ Необязательно | Отчество сотрудника | Иванович |
| Email | ⚪ Необязательно | Email в формате user@domain.com | ivanov@company.ru |
| Подразделение | ⚪ Необязательно | Название подразделения (создаётся автоматически если не существует) | IT отдел |
| Должность | ⚪ Необязательно | Должность сотрудника | Системный администратор |

#### Пример данных:

```
Фамилия    | Имя    | Отчество   | Email                  | Подразделение | Должность
-----------|--------|------------|------------------------|---------------|----------------------
Иванов     | Иван   | Иванович   | ivanov@company.ru      | IT отдел      | Системный администратор
Петрова    | Мария  | Петровна   | petrova@company.ru     | Бухгалтерия   | Главный бухгалтер
Сидоров    | Пётр   |            | sidorov@company.ru     | Отдел продаж  | Менеджер
```

### Особенности импорта:

1. **Автоматическое создание подразделений**
   - Если указанное подразделение не существует, оно будет создано автоматически
   - Список созданных подразделений отображается в результатах импорта

2. **Валидация email**
   - Email проверяется на корректность формата
   - При некорректном формате строка пропускается с ошибкой

3. **Обязательные поля**
   - Фамилия и Имя обязательны для заполнения
   - При отсутствии обязательных полей строка пропускается с ошибкой

## 💻 Импорт оборудования

### Формат файла

Скачайте шаблон через интерфейс: **Система → Импорт данных → Скачать шаблон для оборудования**

#### Структура файла:

| Колонка | Обязательность | Описание | Пример |
|---------|----------------|----------|--------|
| Название | ✅ Обязательно | Название оборудования | Ноутбук Dell XPS 13 |
| Серийный номер | ⚪ Необязательно | Серийный номер | SN123456 |
| Инвентарный номер | ⚪ Необязательно | Инвентарный номер (генерируется автоматически если пустой) | INV-001 |
| Тип | ✅ Обязательно | Тип оборудования (должен существовать в системе) | Ноутбук |
| Категория | ✅ Обязательно | Категория оборудования (должна существовать в системе) | Компьютеры |
| Статус | ✅ Обязательно | Статус оборудования | В эксплуатации |
| Сотрудник (ФИО) | ⚪ Необязательно | ФИО сотрудника в формате "Фамилия Имя Отчество" | Иванов Иван Иванович |
| Помещение | ⚪ Необязательно | Название помещения (должно существовать в системе) | Кабинет 201 |
| Дата покупки | ⚪ Необязательно | Дата в формате YYYY-MM-DD | 2024-01-15 |
| Гарантия до | ⚪ Необязательно | Дата в формате YYYY-MM-DD | 2027-01-15 |
| Процессор | ⚪ Необязательно | Модель процессора | Intel Core i5-12400 |
| ОЗУ (ГБ) | ⚪ Необязательно | Объём оперативной памяти в ГБ | 16 |
| Тип хранилища | ⚪ Необязательно | SSD, HDD или M2 | SSD |
| Объём хранилища (ГБ) | ⚪ Необязательно | Объём хранилища в ГБ | 512 |
| Заметки | ⚪ Необязательно | Дополнительные заметки | Корпоративный ноутбук |

#### Допустимые значения статуса:

- `В эксплуатации` - оборудование используется
- `В резерве` - оборудование в резерве
- `Списан` - оборудование списано
- `В ремонте` - оборудование в ремонте

#### Пример данных:

```
Название          | Серийный номер | Инвентарный номер | Тип      | Категория  | Статус         | Сотрудник                  | Помещение    | Дата покупки | Гарантия до | Процессор          | ОЗУ | Тип хранилища | Объём хранилища | Заметки
------------------|----------------|-------------------|----------|------------|----------------|----------------------------|--------------|--------------|-------------|--------------------|---- -|---------------|-----------------|------------------
Ноутбук Dell XPS  | SN123456       | INV-001           | Ноутбук  | Компьютеры | В эксплуатации | Иванов Иван Иванович       | Кабинет 201  | 2024-01-15   | 2027-01-15  | Intel Core i5-12400| 16  | SSD           | 512             | Корпоративный ноутбук
Монитор LG 27"    | SN789012       | INV-002           | Монитор  | Периферия  | В резерве      |                            | Склад        | 2024-02-10   | 2027-02-10  |                    |     |               |                 |
```

### Особенности импорта:

1. **Типы и категории**
   - Тип и категория должны существовать в системе
   - Если тип не найден, строка пропускается с ошибкой
   - Сначала создайте необходимые типы через: **Структура → Категории и типы**

2. **Привязка к сотрудникам**
   - Сотрудник указывается в формате "Фамилия Имя Отчество"
   - Система ищет сотрудника по ФИО
   - Если сотрудник не найден, поле остаётся пустым
   - Рекомендуется сначала импортировать сотрудников

3. **Привязка к помещениям**
   - Помещение указывается по названию
   - Если помещение не найдено, поле остаётся пустым
   - Сначала создайте необходимые помещения через: **Структура → Помещения**

4. **Даты**
   - Даты должны быть в формате YYYY-MM-DD (например: 2024-01-15)
   - Поддерживаются даты из Excel (автоматическая конвертация)

5. **Инвентарные номера**
   - Если инвентарный номер не указан, генерируется автоматически
   - Формат: `INV-{timestamp}-{index}`

6. **Технические характеристики**
   - Процессор, ОЗУ, тип и объём хранилища заполняются для ПК и ноутбуков
   - Тип хранилища нормализуется к верхнему регистру (SSD, HDD, M2)

## 📊 Результаты импорта

После импорта система отображает:

### Успешный импорт:
- ✅ Количество успешно импортированных записей
- 🏛️ Список созданных подразделений (для импорта сотрудников)
- 👥 Список созданных сотрудников (для импорта сотрудников)
- 💻 Список созданного оборудования (для импорта оборудования)

### Ошибки:
- ❌ Количество ошибок
- 📋 Таблица с ошибками:
  - Номер строки в Excel файле
  - Описание ошибки
  - Данные строки

## 🔄 Рекомендуемый порядок импорта

Для корректной привязки всех связей рекомендуется импортировать данные в следующем порядке:

1. **Подразделения и сотрудники**
   - Импортируйте сотрудников через импорт сотрудников
   - Подразделения создадутся автоматически

2. **Помещения**
   - Создайте помещения через интерфейс: **Структура → Помещения**
   - Или импортируйте через отдельный механизм (если доступен)

3. **Типы и категории оборудования**
   - Создайте типы через интерфейс: **Структура → Категории и типы**

4. **Оборудование**
   - Импортируйте оборудование через импорт оборудования
   - Все связи установятся автоматически

## 💡 Советы и рекомендации

### Подготовка данных:

1. **Используйте шаблоны**
   - Всегда начинайте с официального шаблона
   - Шаблоны содержат правильную структуру и примеры

2. **Проверьте данные перед импортом**
   - Убедитесь, что все обязательные поля заполнены
   - Проверьте формат дат (YYYY-MM-DD)
   - Проверьте корректность email адресов

3. **Избегайте дубликатов**
   - Система не проверяет дубликаты при импорте
   - Проверьте данные на дубликаты перед импортом

### Обработка ошибок:

1. **Исправьте ошибки**
   - Скачайте отчёт об ошибках
   - Исправьте проблемные строки
   - Повторите импорт

2. **Частичный импорт**
   - Успешные строки импортируются даже если есть ошибки
   - Можно импортировать исправленные строки отдельно

### Большие файлы:

1. **Размер файла**
   - Максимальный размер: 10 MB
   - Для больших файлов разбейте на части

2. **Производительность**
   - Импорт 1000 записей занимает ~5-10 секунд
   - Рекомендуется импортировать batches по 500-1000 записей

## 🐛 Решение проблем

### Проблема: "Тип не найден"

**Решение:**
1. Проверьте название типа в Excel
2. Убедитесь, что тип существует в системе
3. Создайте недостающие типы через интерфейс

### Проблема: "Сотрудник не найден"

**Решение:**
1. Проверьте формат ФИО (Фамилия Имя Отчество)
2. Убедитесь, что сотрудник импортирован
3. Проверьте написание (без опечаток)

### Проблема: "Некорректный формат email"

**Решение:**
1. Проверьте формат email (user@domain.com)
2. Удалите пробелы и специальные символы
3. Используйте только латинские буквы

### Проблема: "Некорректная дата"

**Решение:**
1. Используйте формат YYYY-MM-DD
2. Проверьте корректность даты (не 2024-13-45)
3. Убедитесь, что ячейка имеет формат даты в Excel

## 📞 Поддержка

При возникновении проблем:

1. Проверьте логи импорта в интерфейсе
2. Проверьте консоль браузера (F12)
3. Проверьте логи сервера
4. Обратитесь к администратору системы

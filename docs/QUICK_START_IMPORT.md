# 🚀 Быстрый старт: Импорт данных

## 📥 Импорт сотрудников (5 минут)

### Шаг 1: Скачайте шаблон
1. Откройте **Система → Импорт данных**
2. Выберите **Сотрудники**
3. Нажмите **📥 Скачать шаблон для сотрудников**

### Шаг 2: Заполните данные
Откройте скачанный файл в Excel и заполните:

```
Фамилия    | Имя    | Отчество   | Email                  | Подразделение | Должность
-----------|--------|------------|------------------------|---------------|----------------------
Иванов     | Иван   | Иванович   | ivanov@company.ru      | IT отдел      | Системный администратор
Петрова    | Мария  | Петровна   | petrova@company.ru     | Бухгалтерия   | Главный бухгалтер
```

**Важно:**
- ✅ Фамилия и Имя - обязательны
- ⚪ Подразделение - создаётся автоматически если не существует
- ⚪ Остальные поля - необязательны

### Шаг 3: Загрузите файл
1. Сохраните файл в формате XLSX
2. Вернитесь в **Импорт данных**
3. Выберите файл через **Выберите файл Excel**
4. Нажмите **📤 Импортировать**

### Результат:
✅ Сотрудники созданы  
✅ Подразделения созданы автоматически

## 💻 Импорт оборудования (10 минут)

### Шаг 1: Создайте типы оборудования
Перед импортом оборудования создайте типы:

1. Откройте **Структура → Категории и типы**
2. Создайте категории: **Компьютеры**, **Периферия**, **Сетевое оборудование**
3. Создайте типы:
   - Категория: Компьютеры → Типы: **Ноутбук**, **Настольный ПК**
   - Категория: Периферия → Типы: **Монитор**, **Принтер**

### Шаг 2: Скачайте шаблон
1. Откройте **Система → Импорт данных**
2. Выберите **Оборудование**
3. Нажмите **📥 Скачать шаблон для оборудования**

### Шаг 3: Заполните данные
Откройте скачанный файл и заполните:

```
Название          | Серийный номер | Инв. номер | Тип      | Категория  | Статус         | Сотрудник            | Помещение    | Дата покупки | Процессор          | ОЗУ | Хранилище | Объём
------------------|----------------|------------|----------|------------|----------------|----------------------|--------------|--------------|--------------------|-----|-----------|------
Ноутбук Dell XPS  | SN123456       | INV-001    | Ноутбук  | Компьютеры | В эксплуатации | Иванов Иван Иванович | Кабинет 201  | 2024-01-15   | Intel Core i5-12400| 16  | SSD       | 512
Монитор LG 27"    | SN789012       | INV-002    | Монитор  | Периферия  | В резерве      |                      | Склад        | 2024-02-10   |                    |     |           |
```

**Важно:**
- ✅ Название, Тип, Категория, Статус - обязательны
- ⚪ Статус: `В эксплуатации`, `В резерве`, `Списан`, `В ремонте`
- ⚪ Сотрудник указывается в формате "Фамилия Имя Отчество"
- ⚪ Даты в формате YYYY-MM-DD

### Шаг 4: Загрузите файл
1. Сохраните файл в формате XLSX
2. Вернитесь в **Импорт данных**
3. Выберите файл
4. Нажмите **📤 Импортировать**

### Результат:
✅ Оборудование создано  
✅ Привязки к сотрудникам установлены  
✅ Технические характеристики сохранены

## 📊 Проверка результатов

После импорта проверьте:

1. **Сотрудники**: **Структура → Сотрудники**
2. **Подразделения**: **Структура → Подразделения**
3. **Оборудование**: **Структура → Оборудование**

---

## ⚠️ Частые ошибки

### Ошибка: "Тип не найден"
**Решение:** Создайте типы оборудования перед импортом

### Ошибка: "Сотрудник не найден"
**Решение:** Сначала импортируйте сотрудников, затем оборудование

### Ошибка: "Некорректный формат email"
**Решение:** Проверьте формат email (user@domain.com)

### Ошибка: "Некорректная дата"
**Решение:** Используйте формат YYYY-MM-DD (например: 2024-01-15)

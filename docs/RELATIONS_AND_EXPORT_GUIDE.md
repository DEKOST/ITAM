# 🔗📄 Руководство по связям оборудования и экспорту отчётов

## 🔗 Связи между оборудованием

### 📋 Обзор

Система позволяет создавать связи между единицами оборудования для отображения комплектов, компонентов и периферии.

### 🎯 Возможности

1. **Типы связей**
   - **Компонент** - дочернее оборудование является компонентом родительского
   - **Периферия** - периферийное устройство (монитор, клавиатура, мышь)
   - **Аксессуар** - дополнительный аксессуар
   - **Резервное** - резервное оборудование
   - **Связанное** - просто связанное оборудование

2. **Направления связей**
   - **Родительское оборудование** - к чему привязано текущее
   - **Дочернее оборудование** - что привязано к текущему

3. **Визуализация**
   - Отображение всех связей в карточке оборудования
   - Ссылки на связанные устройства
   - Информация о типе связи

### 💡 Примеры использования

#### Пример 1: Комплект рабочего места
```
ПК (родитель)
├── Монитор 1 (дочерний, тип: Периферия)
├── Монитор 2 (дочерний, тип: Периферия)
├── Клавиатура (дочерняя, тип: Периферия)
└── Мышь (дочерняя, тип: Периферия)
```

#### Пример 2: Сервер с компонентами
```
Сервер (родитель)
├── Дополнительный HDD (дочерний, тип: Компонент)
├── Дополнительная RAM (дочерняя, тип: Компонент)
└── ИБП (дочерний, тип: Аксессуар)
```

#### Пример 3: Резервное оборудование
```
Основной ноутбук (родитель)
└── Резервный ноутбук (дочерний, тип: Резервное)
```

### 🔧 Как использовать

#### Добавление связи

1. **Откройте карточку оборудования**
   - Перейдите в "Оборудование" → выберите оборудование

2. **Найдите секцию "Связи оборудования"**
   - Прокрутите вниз до секции с иконкой 🔗

3. **Нажмите "Добавить связь"**

4. **Выберите тип связи**
   - **Добавить дочернее** - если текущее оборудование является родительским
   - **Добавить родительское** - если текущее оборудование является дочерним

5. **Выберите тип отношения**
   - Компонент, Периферия, Аксессуар, Резервное или Связанное

6. **Выберите оборудование**
   - Выберите из списка доступного оборудования

7. **Нажмите "Добавить"**

#### Удаление связи

1. **Найдите связь в списке**
   - В секции "Связи оборудования"

2. **Нажмите кнопку 🗑️**
   - Рядом с нужной связью

3. **Подтвердите удаление**

#### Просмотр связанных устройств

1. **Кликните по названию устройства**
   - В списке связей
   - Откроется карточка связанного устройства

### 📊 Отображение связей

В карточке оборудования отображаются:

**Родительское оборудование:**
- Название устройства
- Тип и инвентарный номер
- Тип связи
- Кнопка удаления

**Дочернее оборудование:**
- Список всех привязанных устройств
- Тип и инвентарный номер каждого
- Тип связи для каждого
- Кнопки удаления

## 📄 Экспорт отчётов в Excel

### 📋 Обзор

Система предоставляет три типа отчётов для экспорта в Excel:
1. Полный список всего оборудования
2. Оборудование конкретного сотрудника
3. Акт приёма-передачи

### 🎯 Возможности

#### 1. Экспорт всего оборудования

**Содержимое отчёта:**
- Название оборудования
- Тип и категория
- Серийный и инвентарный номера
- Статус
- Сотрудник и подразделение
- Помещение
- Даты покупки и гарантии
- Технические характеристики (ЦП, ОЗУ, хранилище)
- Заметки

**Когда использовать:**
- Инвентаризация всего парка техники
- Создание полного реестра
- Анализ оборудования

#### 2. Экспорт по сотруднику

**Содержимое отчёта:**
- Список оборудования, закреплённого за сотрудником
- Название, тип, серийный номер
- Инвентарный номер и статус
- Помещение и даты

**Когда использовать:**
- Передача дел при увольнении
- Проверка оборудования у сотрудника
- Создание списка для конкретного лица

#### 3. Акт приёма-передачи

**Содержимое отчёта:**
- Заголовок "АКТ ПРИЁМА-ПЕРЕДАЧИ ОБОРУДОВАНИЯ"
- Дата создания
- Передающая и принимающая стороны
- Таблица с оборудованием (№, наименование, серийный номер, инвентарный номер, состояние)
- Поля для подписей
- Место для печати

**Когда использовать:**
- Приём оборудования новым сотрудником
- Передача оборудования между сотрудниками
- Возврат оборудования при увольнении

### 🔧 Как использовать

#### Экспорт всего оборудования

1. **Откройте страницу экспорта**
   - Перейдите в "Система" → "Экспорт отчётов"

2. **Выберите тип отчёта**
   - Нажмите "Всё оборудование"

3. **Нажмите "Экспортировать в Excel"**

4. **Файл сохранится в папку "Загрузки"**
   - Имя файла: `Оборудование_YYYY-MM-DD.xlsx`

#### Экспорт по сотруднику

1. **Откройте страницу экспорта**
   - Перейдите в "Система" → "Экспорт отчётов"

2. **Выберите тип отчёта**
   - Нажмите "По сотруднику"

3. **Выберите сотрудника**
   - Из выпадающего списка

4. **Нажмите "Экспортировать в Excel"**

5. **Файл сохранится в папку "Загрузки"**
   - Имя файла: `Оборудование_ФИО_YYYY-MM-DD.xlsx`

#### Создание акта приёма-передачи

1. **Откройте страницу экспорта**
   - Перейдите в "Система" → "Экспорт отчётов"

2. **Выберите тип отчёта**
   - Нажмите "Акт приёма-передачи"

3. **Выберите сотрудника**
   - Которому передаётся оборудование

4. **Нажмите "Экспортировать в Excel"**

5. **Файл сохранится в папку "Загрузки"**
   - Имя файла: `Акт_приёма-передачи_ФИО_YYYY-MM-DD.xlsx`

6. **Распечатайте и подпишите**
   - Откройте файл в Excel
   - Распечатайте
   - Заполните подписи вручную

### 📊 Формат файлов

Все файлы экспортируются в формате **Excel (.xlsx)**:
- Совместимость с Microsoft Excel
- Совместимость с LibreOffice Calc
- Совместимость с Google Sheets
- Поддержка форматирования и стилей

### 💡 Советы по использованию

#### Для инвентаризации:
1. Экспортируйте полный список оборудования
2. Распечатайте список
3. Проведите физическую проверку
4. Внесите отметки в расппечанный список
5. Обновите данные в системе

#### Для передачи дел:
1. Экспортируйте оборудование сотрудника
2. Создайте акт приёма-передачи
3. Распечатайте оба документа
4. Проведите передачу с подписями

#### Для аудита:
1. Экспортируйте полный список
2. Сравните с предыдущим экспортом
3. Выявите изменения
4. Обновите данные

### 🔍 Решение проблем

#### Проблема: Файл не скачивается
**Решение:**
1. Проверьте настройки браузера
2. Разрешите скачивание файлов
3. Проверьте папку "Загрузки"
4. Попробуйте другой браузер

#### Проблема: Файл не открывается в Excel
**Решение:**
1. Убедитесь, что файл имеет расширение .xlsx
2. Обновите Microsoft Excel
3. Попробуйте открыть в LibreOffice
4. Проверьте целостность файла

#### Проблема: Пустой отчёт
**Решение:**
1. Проверьте, есть ли оборудование в системе
2. Для отчёта по сотруднику - проверьте, есть ли у него оборудование
3. Проверьте фильтры и поиск

## 📚 Примеры использования

### Пример 1: Создание комплекта рабочего места

1. Создайте ПК в системе
2. Создайте монитор, клавиатуру, мышь
3. Откройте карточку ПК
4. Добавьте связи:
   - Монитор → тип: Периферия
   - Клавиатура → тип: Периферия
   - Мышь → тип: Периферия
5. Теперь в карточке ПК виден полный комплект

### Пример 2: Экспорт для инвентаризации

1. Перейдите в "Экспорт отчётов"
2. Выберите "Всё оборудование"
3. Экспортируйте в Excel
4. Распечатайте список
5. Проведите физическую проверку
6. Внесите изменения в систему

### Пример 3: Приём оборудования новым сотрудником

1. Перейдите в "Экспорт отчётов"
2. Выберите "Акт приёма-передачи"
3. Выберите нового сотрудника
4. Экспортируйте акт
5. Распечатайте акт
6. Передайте оборудование с подписанием акта

### Пример 4: Передача оборудования между сотрудниками

1. Экспортируйте оборудование текущего владельца
2. Создайте акт возврата
3. Подпишите акт возврата
4. В системе измените привязку оборудования
5. Создайте акт передачи новому владельцу
6. Подпишите акт передачи

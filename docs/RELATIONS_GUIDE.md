# 🔗 Руководство по связям между оборудованием

## 📋 Обзор

Система позволяет создавать связи между единицами оборудования для отображения комплектов, компонентов и периферии.

## 🎯 Возможности

### Типы связей

1. **Компонент** - дочернее оборудование является компонентом родительского
2. **Периферия** - периферийное устройство (монитор, клавиатура, мышь)
3. **Аксессуар** - дополнительный аксессуар
4. **Резервное** - резервное оборудование
5. **Связанное** - просто связанное оборудование

### Направления связей

- **Родительское оборудование** - к чему привязано текущее
- **Дочернее оборудование** - что привязано к текущему

### Визуализация

- Отображение всех связей в карточке оборудования
- Ссылки на связанные устройства
- Информация о типе связи

## 💡 Примеры использования

### Пример 1: Комплект рабочего места

```
ПК (родитель)
├── Монитор 1 (дочерний, тип: Периферия)
├── Монитор 2 (дочерний, тип: Периферия)
├── Клавиатура (дочерняя, тип: Периферия)
└── Мышь (дочерняя, тип: Периферия)
```

### Пример 2: Сервер с компонентами

```
Сервер (родитель)
├── Дополнительный HDD (дочерний, тип: Компонент)
├── Дополнительная RAM (дочерняя, тип: Компонент)
└── ИБП (дочерний, тип: Аксессуар)
```

### Пример 3: Резервное оборудование

```
Основной ноутбук (родитель)
└── Резервный ноутбук (дочерний, тип: Резервное)
```

## 🔧 Как использовать

### Добавление связи

1. **Откройте карточку оборудования**
   - Перейдите в "Оборудование" → выберите оборудование

2. **Найдите секцию "Связи оборудования"**
   - Прокрутите вниз до секции с иконкой 🔗

3. **Нажмите "Добавить связь"**

4. **Выберите тип связи**
   - **Добавить дочернее** - если текущее оборудование является родительским
   - **Добавить родительское** - если текущее оборудование является дочерним

5. **Выберите тип отношения**
   - Компонент, Периферия, Аксессуар, Резервное или Связанное

6. **Выберите оборудование**
   - Выберите из списка доступного оборудования

7. **Нажмите "Добавить"**

8. **Подтверждение**
   - Появится уведомление "Связь успешно добавлена"
   - Связь отобразится в списке

### Удаление связи

1. **Найдите связь в списке**
   - В секции "Связи оборудования"

2. **Нажмите кнопку 🗑️**
   - Рядом с нужной связью

3. **Подтвердите удаление**

### Просмотр связанных устройств

1. **Кликните по названию устройства**
   - В списке связей
   - Откроется карточка связанного устройства

## 📊 Отображение связей

В карточке оборудования отображаются:

### Родительское оборудование

- Название устройства
- Тип и инвентарный номер
- Тип связи
- Кнопка удаления

### Дочернее оборудование

- Список всех привязанных устройств
- Тип и инвентарный номер каждого
- Тип связи для каждого
- Кнопки удаления

## 📚 Примеры использования

### Пример 1: Создание комплекта рабочего места

1. Создайте ПК в системе
2. Создайте монитор, клавиатуру, мышь
3. Откройте карточку ПК
4. Добавьте связи:
   - Монитор → тип: Периферия
   - Клавиатура → тип: Периферия
   - Мышь → тип: Периферия
5. Теперь в карточке ПК виден полный комплект

### Пример 2: Привязка монитора к ПК

1. Откройте карточку монитора
2. Нажмите "Добавить связь"
3. Выберите "Добавить родительское"
4. Выберите тип: Периферия
5. Выберите ПК из списка
6. Нажмите "Добавить"
7. Теперь монитор отображается как дочерний элемент ПК

### Пример 3: Создание резервного оборудования

1. Откройте карточку основного ноутбука
2. Нажмите "Добавить связь"
3. Выберите "Добавить дочернее"
4. Выберите тип: Резервное
5. Выберите резервный ноутбук
6. Нажмите "Добавить"

## 🔍 Решение проблем

### Проблема: Связь не добавляется

**Решение:**
1. Убедитесь, что выбрано оборудование
2. Проверьте, что оборудование не связано само с собой
3. Проверьте консоль браузера на наличие ошибок
4. Обновите страницу и попробуйте снова

### Проблема: Связь не отображается после добавления

**Решение:**
1. Обновите страницу (F5)
2. Проверьте, что связь действительно создана (в БД)
3. Проверьте консоль браузера на наличие ошибок
4. Обратитесь к администратору системы

### Проблема: Нельзя удалить связь

**Решение:**
1. Убедитесь, что у вас есть права на удаление
2. Проверьте консоль браузера на наличие ошибок
3. Обновите страницу и попробуйте снова

## 💡 Советы по использованию

### Организация комплектов

- Создавайте все компоненты комплекта заранее
- Используйте тип "Периферия" для мониторов, клавиатур, мышей
- Используйте тип "Компонент" для внутренних компонентов (HDD, RAM)
- Используйте тип "Аксессуар" для дополнительных устройств

### Именование связей

- Используйте осмысленные типы связей
- Группируйте связанные устройства логически
- Документируйте сложные связи в заметках

### Массовое создание связей

- Создайте все оборудование сначала
- Затем создавайте связи между ними
- Используйте систематический подход (сначала все мониторы, потом все клавиатуры)

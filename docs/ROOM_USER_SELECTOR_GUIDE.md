# 🏢👥 Руководство по выбору помещений и сотрудников

## 📋 Обзор

Система ITAM Service предоставляет улучшенные компоненты для выбора помещений и сотрудников при привязке оборудования. Эти компоненты обеспечивают удобный поиск, группировку и быструю навигацию.

## 🏢 Выбор помещения

### Компонент RoomSelector

Компонент `RoomSelector` используется в форме оборудования для выбора помещения.

#### Возможности:

1. **Поиск**
   - Поиск по названию помещения
   - Поиск по названию здания
   - Поиск по номеру этажа
   - Мгновенная фильтрация результатов

2. **Группировка по зданиям**
   - Помещения автоматически группируются по зданиям
   - Каждое здание отображается с заголовком и иконкой 🏢
   - Счётчик помещений в каждом здании

3. **Интерфейс**
   - Компактный выпадающий список
   - Отображение выбранного помещения с деталями
   - Кнопка сброса выбора
   - Закрытие при клике вне компонента

#### Как использовать:

1. **Откройте форму оборудования**
   - Перейдите в "Оборудование" → "Добавить" или "Редактировать"

2. **Найдите поле "Помещение"**
   - Нажмите на поле для открытия выпадающего списка

3. **Выберите помещение**
   - **Вариант 1**: Используйте поиск
     - Начните вводить название, здание или этаж
     - Результаты фильтруются мгновенно
   - **Вариант 2**: Просмотрите группы
     - Прокрутите список зданий
     - Выберите нужное помещение в группе

4. **Подтвердите выбор**
   - Кликните по помещению
   - Список закроется автоматически
   - Помещение отобразится в поле

## 👥 Выбор сотрудника

### Компонент UserSelector

Компонент `UserSelector` используется в форме оборудования для выбора сотрудника.

#### Возможности:

1. **Поиск**
   - Поиск по ФИО (фамилия, имя, отчество)
   - Поиск по email
   - Поиск по должности
   - Мгновенная фильтрация результатов

2. **Группировка по подразделениям**
   - Сотрудники автоматически группируются по подразделениям
   - Каждое подразделение отображается с заголовком и иконкой 🏛️

3. **Интерфейс**
   - Компактный выпадающий список
   - Отображение выбранного сотрудника с должностью

   - Закрытие при клике вне компонента

2. **Найдите поле "Сотрудник"**

3. **Выберите сотрудника**

## 🏢 Группировка помещений по зданиям

### Страница "Помещения"

На странице "Помещения" доступен режим группировки по зданиям.

#### Возможности:

1. **Два режима просмотра**
   - **По зданиям** - группировка помещений по зданиям
   - **Списком** - обычный список с сортировкой

2. **Группированный вид**
   - Каждое здание отображается как отдельная секция
   - Заголовок здания с иконкой 🏢 и счётчиком помещений
   - Помещения отображаются в сетке внутри секции
   - Удобная навигация по большим спискам

3. **Переключение режимов**
   - Кнопки переключения в верхней части страницы
   - Мгновенное переключение между режимами
   - Сохранение выбранного режима

#### Как использовать:

1. **Откройте страницу "Помещения"**
   - Перейдите в "Структура" → "Помещения"

2. **Выберите режим просмотра**
   - Нажмите "По зданиям" для группированного вида
   - Нажмите "Списком" для обычного списка

3. **В группированном виде**
   - Просмотрите список зданий
   - Каждое здание содержит список помещений
   - Используйте кнопки редактирования и удаления

## 💡 Советы по использованию

### Быстрый поиск помещения

1. **По названию**
   - Введите номер кабинета: "201", "305"
   - Введите название: "Серверная", "Склад"

2. **По зданию**
   - Введите название здания: "Главный", "Второй"
   - Результаты покажут все помещения этого здания

3. **По этажу**
   - Введите номер этажа: "1", "2", "3"
   - Результаты покажут все помещения этого этажа

### Быстрый поиск сотрудника

1. **По фамилии**
   - Введите фамилию: "Иванов", "Петров"
   - Результаты покажут всех сотрудников с такой фамилией

2. **По должности**
   - Введите должность: "администратор", "разработчик"
   - Результаты покажут всех сотрудников с такой должностью

3. **По email**
   - Введите часть email: "ivanov", "@company"
   - Результаты покажут сотрудников с таким email

### Эффективная работа с помещениями

1. **Используйте группированный вид**
   - Когда помещений много (>20)
   - Когда нужно найти помещение в конкретном здании
   - Для быстрого обзора всех помещений здания

2. **Используйте списковый вид**
   - Когда помещений мало (<20)
   - Когда нужна сортировка по определённому полю
   - Для работы с отдельными помещениями

3. **Комбинируйте с поиском**
   - Используйте поиск для быстрой фильтрации
   - Просматривайте результаты в группированном виде
   - Используйте сортировку для упорядочивания

## 🔍 Решение проблем

### Проблема: Помещение не найдено
**Решение:**
1. Проверьте правильность написания
2. Убедитесь, что помещение создано
3. Создайте новое помещение через кнопку "+"

### Проблема: Сотрудник не найден
**Решение:**
1. Проверьте правильность написания ФИО
2. Убедитесь, что сотрудник создан
3. Создайте нового сотрудника через кнопку "+"

### Проблема: Список слишком длинный
**Решение:**
1. Используйте поиск для фильтрации
2. Переключитесь в группированный вид (для помещений)
3. Используйте сортировку для упорядочивания

# 🛠️ Сервисное меню

Сервисное меню содержит опасные операции, которые требуют многоуровневого подтверждения для защиты от случайного выполнения.

## 📍 Расположение

Сервисное меню доступно только для администраторов и находится в разделе **Система** → **🛠️ Сервисное меню**.

## ⚠️ Доступные операции

### Удаление всех связей

Удаляет все связи между оборудованием. Сами единицы оборудования не удаляются.

**Уровни подтверждения:**

1. **Первый уровень** - предупреждение о действии
   - Показывает предупреждение о том, что все связи будут удалены
   - Кнопки: "Да, я уверен" / "Отмена"

2. **Второй уровень** - повторное подтверждение
   - Подчёркивает необратимость действия
   - Кнопки: "Да, удалить все" / "Отмена"

3. **Третий уровень** - финальное подтверждение
   - Красное предупреждение с текстом "ПОСЛЕДНЕЕ ПРЕДУПРЕЖДЕНИЕ!"
   - Кнопки: "🗑️ ДА, УДАЛИТЬ ВСЁ" / "Отмена"

**Как использовать:**

1. Откройте **Система** → **🛠️ Сервисное меню**
2. Нажмите кнопку "🗑️ Удалить все связи"
3. Подтвердите действие на первом уровне
4. Подтвердите на втором уровне
5. Подтвердите на третьем уровне
6. Дождитесь завершения операции

**Результат:**
- Все связи между оборудованием будут удалены
- Сами единицы оборудования останутся
- Вы увидите сообщение с количеством удалённых связей
- После удаления можно создать новые связи между оборудованием

## 💡 Когда использовать

**Используйте эту функцию, когда:**
- Нужно удалить все связи и начать заново
- Связи были созданы ошибочно в массовом порядке
- Нужно очистить базу данных связей

**НЕ используйте эту функцию, когда:**
- Нужно удалить только некоторые связи (используйте удаление отдельных связей)
- Не уверены в последствиях
- Не сделали резервную копию базы данных

## ⚠️ Важные предупреждения

1. **Необратимость** - после удаления связей восстановить их автоматически невозможно
2. **Резервная копия** - перед выполнением операции рекомендуется создать резервную копию базы данных
3. **Трёхуровневое подтверждение** - защищает от случайного нажатия
4. **Только для администраторов** - операция доступна только пользователям с ролью администратора

## 🔒 Безопасность

- Операция требует трёх последовательных подтверждений
- Каждое подтверждение должно быть явным (нажатие кнопки)
- Отмена возможна на любом уровне подтверждения
- Операция логируется в журнале действий

## 📊 Пример использования

**Сценарий:** Нужно удалить все связи и создать новые

1. Создайте резервную копию: **Система** → **💾 Резервные копии** → **Создать бэкап**
2. Откройте **Система** → **🛠️ Сервисное меню**
3. Нажмите "🗑️ Удалить все связи"
4. Подтвердите три раза
5. Дождитесь завершения
6. Создайте новые связи через карточки оборудования

## 🔄 Восстановление после удаления

Если вы удалили связи по ошибке:

1. Откройте **Система** → **💾 Резервные копии**
4. Найдите бэкап, созданный до удаления
5. Нажмите "Восстановить"
6. Подтвердите восстановление
7. Перезапустите сервер

## 📝 Примечания

- Операция удаления связей не удаляет сами единицы оборудования
- После удаления связей вы можете создать новые связи
- Рекомендуется создавать резервную копию перед выполнением опасных операций
- Все опасные операции логируются в системе

# 🔼 Руководство по сортировке данных

## 📋 Обзор

Система ITAM Service поддерживает сортировку данных во всех списках и таблицах. Сортировка позволяет упорядочивать данные по различным полям в возрастающем или убывающем порядке.

## 🖱️ Как использовать сортировку

### В таблицах (Сотрудники, Оборудование)

1. **Сортировка по колонке**
   - Кликните по заголовку колонки (ФИО, Email, Название, Тип и т.д.)
   - Данные отсортируются по возрастанию (алфавитный порядок)
   - Появится стрелка вверх ↑ рядом с заголовком

2. **Смена направления сортировки**
   - Кликните по тому же заголовку ещё раз
   - Данные отсортируются по убыванию (обратный алфавитный порядок)
   - Стрелка изменится на ↓ вниз

4. **Отмена сортировки**
   - Кликните по заголовку третий раз
   - Сортировка будет отменена
   - Стрелки исчезнут

### В карточках (Подразделения, Помещения, Шаблоны)

1. **Выбор поля для сортировки**
   - Используйте выпадающий список "Сортировать по..."
   - Выберите нужное поле (Название, Здание, Этаж и т.д.)

2. **Смена направления**
   - Нажмите кнопку ↑/↓ рядом с выпадающим списком
   - Кнопка показывает текущее направление сортировки

## 📋 Доступные поля для сортировки

### 👥 Сотрудники
- **ФИО** - фамилия, имя, отчество
- **Email** - адрес электронной почты
- **Подразделение** - название подразделения
- **Должность** - должность сотрудника

### 💻 Оборудование
- **Название** - название оборудования
- **Тип** - тип оборудования (Ноутбук, Монитор и т.д.)
- **Статус** - статус оборудования (В эксплуатации, В резерве и т.д.)
- **Сотрудник** - ФИО сотрудника, которому назначено оборудование
- **Помещение** - название помещения, где находится оборудование

### 🏛️ Подразделения
- **Название** - название подразделения
- **Родительское подразделение** - название родительского подразделения

### 🏢 Помещения
- **Название** - название помещения (кабинет, серверная и т.д.)
- **Здание** - название здания
- **Этаж** - номер этажа

### 📋 Шаблоны оборудования
- **Название** - название шаблона
- **Тип** - тип оборудования шаблона

## 💡 Особенности сортировки

### Алфавитная сортировка
- Сортировка строк выполняется с учётом русской локали
- Правильная сортировка русских и английских символов
- Регистронезависимая сортировка (А = а)

### Числовая сортировка
- Числовые поля (этаж, ОЗУ, объём хранилища) сортируются по числовому значению
- Правильная сортировка: 1, 2, 10 (а не 1, 10, 2)

### Сортировка связанных данных
- При сортировке по связанным полям (подразделение, сотрудник, помещение) используется название связанной записи
- Пустые значения сортируются в конце списка

### Комбинирование с фильтрами
- Сортировка работает совместно с фильтрами и поиском
- Сначала применяются фильтры, затем сортировка
- Можно фильтровать данные и сортировать отфильтрованные результаты

## 🔄 Сброс сортировки

### В таблицах
- Кликните по заголовку колонки три раза
- Или кликните по другому заголовку для смены поля сортировки

### В карточках
- Выберите другое поле в выпадающем списке
- Или обновите страницу (F5)

## 📊 Сортировка и экспорт

При экспорте данных в Excel или CSV:
- Данные экспортируются в текущем отсортированном порядке
- Если данные отфильтрованы, экспортируются только отфильтрованные записи
- Сортировка сохраняется в экспортируемом файле

## 🐛 Решение проблем

### Проблема: Сортировка не работает
**Решение:**
1. Обновите страницу (F5)
2. Очистите кэш браузера
3. Проверьте консоль браузера на наличие ошибок

### Проблема: Сортировка работает неправильно
**Решение:**
1. Убедитесь, что данные корректны
2. Проверьте, не применены ли фильтры
3. Попробуйте отменить сортировку и применить снова

### Проблема: Медленная сортировка
**Решение:**
1. Сортировка выполняется на клиенте и зависит от количества записей
2. При большом количестве записей (>1000) сортировка может занимать несколько секунд
3. Используйте фильтры для уменьшения количества отображаемых записей

## 💡 Советы по использованию

### Быстрая сортировка
- Используйте сортировку для быстрого поиска данных
- Сортировка по ФИО помогает быстро найти сотрудника
- Сортировка по статусу группирует оборудование по состоянию

### Комбинирование функций
1. Отфильтруйте данные (например, только оборудование в ремонте)
2. Отсортируйте по дате (самое старое сначала)
3. Экспортируйте результат в Excel

### Работа с большими списками
- Используйте поиск для быстрого нахождения записей
- Применяйте фильтры для уменьшения списка
- Сортируйте для упорядочивания отфильтрованных данных

## 📚 Примеры использования

### Пример 1: Поиск самого старого оборудования
1. Откройте список оборудования
2. Кликните по заголовку "Дата покупки"
3. Кликните ещё раз для сортировки по убыванию
4. Первое оборудование в списке - самое старое

### Пример 2: Группировка по подразделениям
1. Откройте список сотрудников
2. Кликните по заголовку "Подразделение"
3. Сотрудники сгруппируются по подразделениям

### Пример 3: Поиск оборудования по сотруднику
1. Откройте список оборудования
2. Кликните по заголовку "Сотрудник"
3. Используйте поиск для фильтрации по ФИО
4. Все оборудование сотрудника будет в начале списка
